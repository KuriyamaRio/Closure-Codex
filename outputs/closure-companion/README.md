# 可露希尔 · Codex 桌宠

这是跟随 Windows 版 Codex 窗口的本机桌宠。它复用 DSH 插件的可露希尔 Spine 3.8 模型、原始动作混合、四种音效、Ark Pixel 气泡、拖拽和右键设置。独立透明窗口会在 Codex 处于前台时显示，切到其他应用或最小化 Codex 时隐藏。

## 开始使用

1. 在资源管理器中双击 `launch.cmd`，然后回到 Codex 窗口。在本工作区中，启动器使用已准备好的 Electron 45.4.1 Windows x64 运行时。
2. 左键点击人物会播放互动动作并弹出气泡。按住人物拖拽可调整位置，松开后吸附。右键可调整大小、镜像、透明度、音效和气泡。
3. 在 Windows 通知区域右键点击可露希尔图标，可以隐藏或退出桌宠。回到前台的 Codex 窗口时，桌宠显示在 Codex 和 CRT 扫描线之上。

随 Codex 自动运行时，桌宠无托盘图标，仍可右键点击角色打开设置。

点击人物时随机轮换七句《明日方舟》原台词，每句播过一遍后重新洗牌。右键设置里的「角色配音」可关闭人声，「配音语言」可选择普通话、日语、英语或韩语，字幕使用简体中文。「配音音量」滑块与音效音量独立。

右键面板中的「预览表情」可单独播放哭脸、委屈待机、庆祝、开场、思考、说话或两段互动。「CRT 显示效果」可分别开关扫描线和暗角，调节强度或选择深浅模式。CRT 设置立即应用并在重启后保留。

如果已打开其他桌宠实例，先从托盘退出再切换启动方式。Codex 默认窗口太小时会暂时隐藏这只桌宠。

### Codex 活动与额度

随 Codex 联动启动时自动启用。手动运行时可双击 `launch-with-activity.cmd` 启用。桌宠只读本机 Codex 会话的活动记录，用像素气泡和原版动作呈现处理中、输出、任务完成、中断和可识别的失败。它合并本机活动，无法判断前台窗口正在显示哪个聊天。手动 `launch.cmd` 提供开场演出和人物交互。

联动启动后，桌宠依据 Codex 的有效用户配置检测提供商，并约每分钟查询一次。官方 ChatGPT 登录显示 Codex 各时间窗口的剩余百分比。合聚 API 使用配置中对应的令牌查询所属账号钱包余额，保留接口返回的额度单位，收到限流时延长查询间隔。其他第三方线路暂未接入。额度查询失败时隐藏读数。

有效额度或余额会加入点击气泡的台词轮换。Codex 位于前台且气泡空闲时，约每分钟自动显示一次。官方额度低于或等于 10% 时仍会触发低额度反应，像素贴画显示主时间窗口的剩余比例。

### 运行参数与位置

- `launch.cmd --demo` 打开测试窗口，便于检查人物和设置面板。`launch.cmd --canvas` 强制使用原项目的 Canvas 2D 回退模式。
- 如果移动桌宠目录，可设置 `CLOSURE_ELECTRON_EXE` 为 Electron 45 Windows x64 的完整 `electron.exe` 路径。运行数据默认存在工作区的 `work/companion-profile`，可用 `CLOSURE_STATE_DIR` 指定别处。
- 模型、视觉和音频资源通过本机文件加载。额度查询使用本机 Codex 登录状态或合聚配置，桌宠不会写入 Codex 配置或安装目录。
